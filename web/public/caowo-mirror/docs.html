什么是 API 中转站？
简单来说，Caowo 帮你转发请求到上游模型服务。你不需要翻墙、不需要海外信用卡，只需要在支持的工具里填入我们的地址和密钥，就能直接使用 GPT 与 Claude 系列模型。

🚀快速开始（3分钟上手）

✅
只需要记住两样东西：API 地址和API 密钥，就能在任何支持的工具中使用。
📋 接入信息
API 地址https://api.caowo.de
API 密钥在控制台创建（sk-开头），见下方教程
兼容格式OpenAI API（/v1/chat/completions） / Anthropic Messages（/v1/messages，限 Claude Code）

快速验证

在终端运行以下命令，确认你的密钥可以正常使用：

curl https://api.caowo.de/v1/chat/completions \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4",
    "messages": [{"role": "user", "content": "你好"}]
  }'
💡
如果你不会用终端也没关系！直接往下看你常用的工具（Cursor、Cherry Studio 等）的图文教程就行。

📝注册与获取密钥

打开 Caowo 控制台
在浏览器中访问 https://api.caowo.de，点击右上角「登录」按钮。
注册账号
如果没有账号，点击「注册」，输入用户名和密码即可完成注册。注册成功后会自动登录。
创建 API 密钥
登录后进入「控制台」→ 点击左侧菜单「令牌」→ 点击右上角「添加令牌」→ 给密钥起个名字 → 点击提交。
复制密钥
创建成功后会显示一个 sk- 开头的密钥字符串。请立即复制并保存好，它只会显示一次！
⚠️
密钥安全提示
API 密钥等同于你的账号密码，不要分享给别人，不要提交到 GitHub 等公开平台。如果泄露了，请立即在控制台删除并重新创建。

⌨️Cursor 接入教程

Cursor 是最流行的 AI 编程 IDE，以下是详细配置步骤：

打开 Cursor 设置
启动 Cursor，按 Ctrl+Shift+J（Mac: ⌘+Shift+J）打开设置，或者点击左下角齿轮图标 → Settings。
找到 Models 设置
在设置页面左侧找到「Models」选项。你会看到模型列表和 API Key 配置区域。
添加模型
点击 + Add Model 按钮，在输入框中精确输入模型名称，如 gpt-5.4，然后回车确认。可以添加多个模型。
填写 API Key
在页面中找到 OpenAI API Key 输入框，填入你在 Caowo 创建的密钥（sk- 开头的那串字符）。
设置 API 地址 ⚡ 关键步骤
点击 OpenAI API Key 下方的 Override OpenAI Base URL 链接，会弹出一个输入框，填入：
https://api.caowo.de/v1
⚠️ 注意结尾要带 /v1，不能省略！
验证连接
点击 Verify 按钮。如果显示绿色 ✅，恭喜你配置成功！如果报错，请检查密钥和地址是否填写正确。
开始使用
回到编辑器，在聊天面板或 Composer 中选择你刚添加的模型（如 gpt-5.4），即可开始使用。
⚠️
常见错误
• Base URL 忘记加 /v1 → 会报 404
• 模型名拼写错误 → 会报 model not found
• 密钥复制不完整 → 会报 401 unauthorized

🍒Cherry Studio 接入教程

Cherry Studio 是一款国产免费 AI 对话客户端，界面美观，支持多模型切换。

下载安装 Cherry Studio
前往 cherry-ai.com 下载，支持 Windows / Mac / Linux。安装后打开。
进入模型服务商设置
点击左下角「设置」图标 → 选择「模型服务商」→ 点击「添加」。
选择 OpenAI 兼容
服务商类型选择 OpenAI 兼容（不是选 OpenAI）。
填写配置
• 名称：随便填，比如「Caowo」
• API 地址：https://api.caowo.de/v1
• API Key：你的密钥（sk-开头）
添加模型
点击「获取模型列表」自动拉取，或手动点「添加模型」输入模型名如 gpt-5.4。
开始对话
回到主界面，在顶部模型选择器中选择刚配置的模型，就可以开始聊天了！

💬ChatBox 接入教程

下载 ChatBox
前往 chatboxai.app 下载安装。
打开设置
点击左下角「设置」→ 「AI 模型提供方」。
选择 OpenAI API 兼容
在「AI 提供方」下拉菜单中选择 OpenAI API Compatible。
填写信息
• API Domain：https://api.caowo.de（注意这里不加 /v1）
• API Key：你的密钥
• Model：手动输入 gpt-5.4
保存并使用
点击「Save」保存，回到对话界面即可使用。

🖥️Codex CLI 接入教程

📌
说明
Codex CLI 教程仅适用于 GPT / Codex 系列模型。Claude 系列模型请仅在 Claude Code 官方客户端中使用，不要套用第三方工具教程。

🦀OpenClaw 接入教程

OpenClaw 是 AI Agent 运行框架，让 AI 自主执行复杂任务。

安装 OpenClaw
npm install -g openclaw
编辑配置文件
打开 ~/.openclaw/openclaw.json，设置：
{
  "agents": {
    "defaults": {
      "model": "gpt-5.4",
      "provider": "openai-compatible",
      "apiKey": "sk-你的密钥",
      "baseUrl": "https://api.caowo.de/v1"
    }
  }
}
启动
openclaw gateway start

🐍Python 接入

安装 OpenAI SDK
pip install openai
编写代码
from openai import OpenAI

client = OpenAI(
    api_key="sk-你的密钥",
    base_url="https://api.caowo.de/v1"
)

response = client.chat.completions.create(
    model="gpt-5.4",
    messages=[{"role": "user", "content": "你好！"}]
)

print(response.choices[0].message.content)

🟢Node.js 接入

🚫暂不支持的平台

⚠️ 不支持 Windsurf

Windsurf 不支持自定义 API 地址，无法接入第三方中转站。建议使用 Cursor 作为替代。

⚠️ 不支持 TRAE（字节跳动 AI IDE）

TRAE 的模型服务商是固定的，不支持自定义 API 地址。建议使用 Cursor 或 Cherry Studio。

⚠️ 不支持 第三方 Claude 工具 / 第三方 Claude 壳

Claude 系列模型仅限 Claude Code 官方客户端。任何第三方 Claude 工具、魔改客户端、共享脚本、二次封装服务或分发中转均不支持，违规会被封禁且不退款。

📡API 参考

端点列表
POST /v1/chat/completions对话补全（主要接口）
POST /v1/messagesClaude / Anthropic 消息接口（限 Claude Code）
GET /v1/models获取可用模型列表
请求头
Authorization: Bearer sk-你的密钥
Content-Type: application/json
请求体示例
{
  "model": "gpt-5.4",
  "messages": [
    {"role": "system", "content": "你是一个有帮助的助手"},
    {"role": "user", "content": "介绍一下你自己"}
  ],
  "max_tokens": 1000,
  "temperature": 0.7,
  "stream": true
}
支持的参数
参数类型必填说明
modelstring✅模型名称
messagesarray✅对话消息列表
max_tokensint最大生成长度
temperaturefloat随机性，0-2，默认 1。越低越确定，越高越有创意
streambool是否流式输出（推荐开启，体验更好）
top_pfloat核采样参数，通常和 temperature 二选一调节

❓常见问题

报错 401 Unauthorized 怎么办？▼
密钥不正确或已过期。请检查：
① API Key 是否完整复制（sk-开头）
② 是否有多余空格
③ 到控制台确认该密钥是否被删除或禁用
④ 重新创建一个新密钥试试
报错 "model not found" 怎么办？▼
模型名拼写错误。请严格使用文档中列出的模型名，区分大小写。常见错误：
❌ GPT-5.4（大写不行）
❌ gpt5.4（少了横杠）
✅ gpt-5.4（正确）
报错 404 Not Found 怎么办？▼
API 地址填写不正确。请确认：
① 有些工具需要 https://api.caowo.de/v1（带 /v1）
② 有些工具只需 https://api.caowo.de（不带 /v1）
具体看上方对应工具的教程。
支持流式输出吗？▼
支持。设置 "stream": true 即可，返回格式为 SSE（Server-Sent Events）。大部分客户端默认就是流式输出，无需额外设置。
响应很慢或超时怎么办？▼
复杂问题或长对话可能需要较长时间（1-3分钟）。如果经常超时：
① 尝试减少消息长度或 max_tokens
② 使用 gpt-5.4-mini 替代，速度更快
③ 开启 stream 模式，边生成边显示
可以用在哪些客户端？▼
任何支持自定义 OpenAI API 地址的客户端都可以，包括但不限于：Cherry Studio、ChatBox、Lobe Chat、OpenCat、BotGem、Cursor、Codex CLI、OpenClaw 等。

不支持的：Windsurf、TRAE（它们不允许自定义 API 地址）。
Claude 系列模型可以在哪些工具里使用？▼
Claude 系列模型仅限 Claude Code 官方客户端。禁止在第三方工具、第三方 Claude 壳、共享脚本、公共中转或任何商业化场景中使用。平台会结合登录 IP、调用 IP、并发和共享行为进行检测；一经确认违规，将直接封禁账号或令牌，且不予退款。
API Key 在哪里获取？▼
登录 api.caowo.de → 控制台 → 令牌 → 添加令牌。详见上方「注册与获取密钥」教程。
